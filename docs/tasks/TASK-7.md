# **Внедрение связей между задачами (Parent, Depends On, Related)**

**Контекст:** Ты — ИИ-ассистент, помогающий разрабатывать VSCode-плагин "Docs Tasks" (репозиторий: `taraswww777/vscode-plugin-docs-tasks`). Плагин управляет задачами из markdown-файлов с YAML frontmatter.

**Цель:** Расширить функциональность плагина, добавив поддержку связей между задачами. Это позволит пользователям создавать иерархии (родительские задачи), указывать блокировки (зависимости) и произвольные связи.

**Требования к реализации на основе выбранного подхода:**

1.  **Расширить интерфейс задачи (TypeScript):**
    *   Найти или создать файл с типами/интерфейсами для задачи (возможно, в `src/types.ts` или `src/task.ts`).
    *   Добавить в интерфейс `Task` три опциональных поля:
        *   `parent?: string;` // ID родительской задачи
        *   `dependsOn?: string;` // ID задачи, которая блокирует текущую
        *   `related?: string[];` // Массив ID связанных задач

2.  **Обновить парсер YAML frontmatter:**
    *   Найти функцию, которая читает и парсит frontmatter из `TASK-*.md` файлов.
    *   Обеспечить, чтобы новые поля (`parent`, `dependsOn`, `related`) корректно извлекались и приводились к нужным типам (строка для первых двух, массив строк для третьего).

3.  **Модифицировать редактор метаданных (UI):**
    *   Найти компонент или функцию, отвечающую за отображение и редактирование полей frontmatter в таблице/интерфейсе плагина.
    *   Добавить в интерфейс редактирования новые поля:
        *   Поле ввода для `parent` (текстовое поле для ID).
        *   Поле ввода для `dependsOn` (текстовое поле для ID).
        *   Поле для `related` (возможно, теги-подобный ввод или текстовое поле, где ID разделяются запятыми).
    *   Убедиться, что при сохранении изменений обновленный frontmatter правильно записывается обратно в файл.

4.  **Отобразить связи в основной таблице:**
    *   Найти код, который рендерит таблицу задач (предположительно, WebView).
    *   Добавить новые колонки (или расширить существующие) для отображения значений `parent`, `dependsOn` и `related`.
    *   Сделать ID задач в этих колонках кликабельными. При клике должна открываться соответствующая задача (файл `TASK-<ID>.md`).

5.  **Реализовать базовую проверку целостности (Валидация):**
    *   При обновлении индекса задач (функция обновления) добавить проверку: существуют ли задачи с ID, указанными в новых полях.
    *   Если обнаружена "битая" ссылка (ID не найден), выводить предупреждение в консоль или в статус-бар плагина.

**Инструкция для выполнения:**

1.  **Проанализируй структуру кода** в папке `src/`, чтобы найти файлы, отвечающие за:
    *   Определение типов данных задачи (интерфейс).
    *   Парсинг и индексацию файлов задач.
    *   Редактор метаданных (WebView или другой UI).
    *   Рендеринг таблицы задач.
    *   Логику обновления индекса.

2.  **Предложи конкретные изменения** для каждого из пунктов, описанных в разделе "Требования к реализации". Приведи фрагменты кода (старый и новый) или опиши алгоритм действий.

3.  **Обрати внимание** на стиль кода проекта (используется TypeScript, возможно, React для WebView), чтобы новые изменения органично вписывались в существующую архитектуру.

**Критерии успеха:**
*   После внесения изменений плагин компилируется без ошибок.
*   В frontmatter файлов задач можно добавить поля `parent`, `dependsOn`, `related`.
*   Эти поля отображаются в таблице и доступны для редактирования через редактор метаданных.
*   Клик по ID связанной задачи в таблице открывает соответствующий файл.
*   При обновлении индекса появляются предупреждения о несуществующих ID в связях.
