| `docs-tasks.openTablePanel` | строка статуса «Docs Tasks», кнопка на панели **Проводника**, палитра | Таблица задач во вкладке редактора |

## Commit with Date

Быстрый коммит уже **проиндексированных** изменений с меткой времени в сообщении.

Реализация: `src/extension.ts`.

**Поведение:**

1. Проверяется открытый workspace и встроенное расширение **Git** (`vscode.git`, API v1).
2. Ищется репозиторий, чей `rootUri` совпадает с корнем workspace (`workspace.rootPath`).
3. В поле ввода подставляется сообщение по умолчанию: `YYYY-MM-DD HH-MM-SS` (локальное время; в части времени дефисы вместо двоеточий).
4. После подтверждения вызывается `repository.commit(message)` — коммитятся только файлы в **Staged Changes**.

**Ограничения:** один Git-репозиторий на корень workspace; при отсутствии репо, Git API или несовпадении пути — предупреждение в UI.
